# Иконки приложения

Сюда загружайте SVG (предпочтительно) или PNG @2x/@3x.

## Структура

```
icons/
├── nav/          # нижняя навигация (5 табов)
├── actions/      # лайк, репост, фильтр, «+» и т.д.
└── common/       # прочие UI-иконки
```

## Рекомендуемые имена

### `nav/` (таб-бар)

| Файл | Назначение |
|------|------------|
| `feed.svg` | Лента |
| `map.svg` | Карта |
| `create.svg` | Создать маршрут (+) |
| `routes.svg` | Мои маршруты |
| `profile.svg` | Профиль |

При необходимости — варианты `_active.svg` для выбранного таба.

### `actions/`

| Файл | Назначение |
|------|------------|
| `filter.svg` | Фильтры |
| `heart.svg` / `heart_filled.svg` | Лайк |
| `repost.svg` | Репост |
| `location.svg` | Город / гео |

## Формат

- **SVG** — один файл, масштабируется (нужен пакет `flutter_svg`, подключим в UI-kit).
- **PNG** — положите в `nav/2.0x/` и `nav/3.0x/` при необходимости (@2x, @3x).

После добавления файлов: `flutter pub get` (assets уже прописаны в `pubspec.yaml`).
