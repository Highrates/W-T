Можно добавлять `06.jpg`, `07.jpg` … — допишите записи в `lib/features/people/data/people_mock.dart`.

## Требования

- Ориентация: **вертикальная**, лицо/фигура по центру, низ кадра не обрезайте сильно (там градиент и имя).
- Размер: от **1080×1440** достаточно; @2x/@3x не обязательны (один файл на человека).
- После добавления: **hot restart** (`R`), не только reload.

Если файла нет — показывается цветной placeholder до загрузки ассетов.
